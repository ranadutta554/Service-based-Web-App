🚀 Project Type
Full Stack Web Application | Service Booking Platform | Authentication | REST API

📌 Overview
A full-stack Service Booking Web Application where users can explore services, create bookings, and manage their service requests online.
This project demonstrates real-world concepts like user authentication, REST API integration, booking management, responsive UI design, and database connectivity, making it highly relevant for full-stack development and campus placements.
